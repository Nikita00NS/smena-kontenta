# Документы проекта: откуда берутся и как пересобрать

Все PDF в `assets/docs/` собирает одна команда из одного набора данных.

```bash
pip install reportlab pypdf        # один раз
python3 tools/docs/build.py        # собрать все документы и обновить список на сайте
python3 tools/docs/build.py --check   # ничего не менять: проверить, что файлы совпадают с текстами
python3 tools/docs/sync-project.py    # перенести данные проекта на сайт (SC.project в data.js)
```

## Что где лежит

| Файл | Что в нём |
|---|---|
| `project.json` | Данные проекта: директор, сооснователь, оператор персональных данных, почта, хостинг, сроки. **Имена и адреса меняются только здесь.** |
| `layout.py` | Шрифты и два оформления: строгий документ (`Official`) и материал для людей (`Brand`). |
| `legal.py` | Политика, пользовательское соглашение, согласие на обработку данных, согласие на распространение. |
| `guides.py` | Пресс-кит, кодекс редакции, памятка автору, программа медиашколы. |
| `build.py` | Запуск. Здесь же список документов для страницы `/docs`: название, описание, порядок. |
| `sync-project.py` | Переносит `project.json` в `assets/js/data.js` (без ИНН и служебных пометок). |

## Как поменять что-то в документах

- **Имя, почту, адрес оператора, срок карты** — в `project.json`, затем обе команды: `sync-project.py` и `build.py`.
- **Формулировку** — в `legal.py` или `guides.py`, затем `build.py`.
- **Дату и номер редакции документов** — `docsDate` и `docsVersion` в `project.json`.
- **Новый документ** — функция в `legal.py` или `guides.py` и строка в списке `DOCS` в `build.py`.

Сборка повторяемая: если текст не менялся, PDF не изменится ни на байт.

## Два бланка на один лист

`soglasie-na-obrabotku-pd.pdf` и `soglasie-na-rasprostranenie-pd.pdf` обязаны помещаться на одну
страницу каждый: сборщик сам считает страницы и сообщает об ошибке, если текст не влез.

## Чего сейчас не хватает

Сборщик печатает предупреждение, пока в `project.json` пусто поле `operator.address`:
по п. 3 ч. 4 ст. 9 закона № 152-ФЗ в согласии должен стоять адрес оператора. Как только адрес
появится — впишите его и пересоберите документы: он встанет в шапку обоих бланков и в политику.

## Документы, которых нет в виде PDF

«Решение о присвоении пресс-карты» и «Заявление на открытие редакции» — именные. Сайт собирает
их из данных сервера на страницах `/card-doc` и `/editorial-doc` и печатает обычной печатью
браузера. Имена директора, сооснователя и оператора в них — тоже из `project.json`.

## Важно

Тексты подготовлены по закону № 152-ФЗ, но это не заключение юриста. Перед публикацией их
должен посмотреть юрист — особенно всё, что касается несовершеннолетних авторов и оператора.

# Проверки проекта

Запускаются на компьютере, сайт и хостинг не трогают. Нужен Node.js 20+.

```bash
# один раз: поставить зависимости проверок вне репозитория
mkdir -p /tmp/sk-tests && cp tools/tests/package*.json /tmp/sk-tests/ && (cd /tmp/sk-tests && npm ci)
export NODE_PATH=/tmp/sk-tests/node_modules

# всё сразу
bash tools/tests/run-all.sh
```

| Проверка | Что смотрит | Сколько идёт |
|---|---|---|
| `php-syntax.js` | Синтаксис всех файлов `api/**/*.php` | секунды |
| `i18n-check.js` | Переводы интерфейса заполнены на всех языках | секунды |
| `pages-smoke.js` | Каждая страница сайта открывается без ошибок; все подключённые файлы существуют | ~20 с |
| `api-checks.js` | Сервер: права, согласия, карты, редакции, отчёты, медиашкола — на настоящем `api/index.php` (PHP в wasm) | ~1 мин |
| `ui-checks.js` | Интерфейс поверх того же сервера: кабинет, панель, документы, медиашкола; сверка кода клиента и сервера | ~30 с |
| `python3 tools/docs/build.py --check` | PDF в `assets/docs` совпадают с текстами и `project.json` | секунды |
| `python3 tools/docs/sync-project.py --check` | Данные проекта на сайте совпадают с `project.json` | секунды |

`probe.js` — не проверка, а быстрый просмотр: что нарисует страница под выбранным демо-аккаунтом.
`ui-kit.js` — общий стенд для `ui-checks.js` и `probe.js`.

Чего проверки не видят: вёрстку, цвета, печать. Это смотрится глазами в просмотре:
`node tools/preview/server.js` → http://localhost:8080 (демо-аккаунты и «почта» — на /__preview).

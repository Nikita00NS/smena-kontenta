# Полный аудит системы — 6 ноября 2026

Проверка сделана по коду и на настоящем PHP (`tools/tests/api-checks.js`, 76
проверок). Ниже — что найдено и что с этим сделано. Всё, что помечено

## 1. Критические: найдено и исправлено

| Что было | Чем грозило | Что сделано |
|---|---|---|
| Функции своего IMAP-клиента назывались `imap_list()`, `imap_append()` | На хостинге включено расширение `imap` → «Cannot redeclare» → **весь API отдавал пустой ответ**. Так и случилось в проде на 40 минут | Все функции переименованы в `imapc_*` |
| HTML письма из внешнего мира вставлялся в админку как есть | Чужое письмо могло выполнить скрипт в панели администратора (кража токена) | Письмо показывается в `<iframe sandbox="">`: скрипты не исполняются, внешние загрузки запрещены |
| `mb_strtoupper()` в проверке слова «УДАЛИТЬ» | На сборках без mbstring — fatal error вместо удаления | Добавлен `supper()` с запасным вариантом |
| Удалённого аккаунта не существовало как функции | Человек не мог уйти из проекта сам | Новый маршрут `account-delete`: пароль + слово УДАЛИТЬ, стирание ПД, закрытие сессий, письмо, журнал |
| Удалённые аккаунты попадали в список участников | Мусор в админке | Скрыты, показываются только с `includeDeleted` |
| В ответах API не было запрета встраивания | Кликджекинг | `X-Frame-Options: DENY` и `Content-Security-Policy: default-src 'none'` |

## 2. Проверено и в порядке

- **Права**: каждый админский маршрут проверяет полномочие на сервере
  (`require_cap`, `require_editor_or_admin`, `is_editor`). Интерфейс ничего не
  решает.
- **Публичные маршруты** (`state`, `points-rules`, `points-leaderboard`,
  `support-send`, `reg`, `login`, `media`, `founders`, `editorial-list`) —
  отдают только то, что можно показывать: без почты, заметок и внутренних
  пометок.
- **Диагностика** (`diag`, `selftest*`, `backups`) закрыта паролем редакции или
  ролью; без пароля отвечает 404 — сам факт существования не подтверждается.
- **Токены**: 60 дней, хранятся на сервере, закрываются при смене пароля и при
  удалении аккаунта; после приостановки не работают.
- **Пароли**: `password_hash` (bcrypt), минимум 8 символов, в открытом виде не
  хранятся и не логируются.
- **Загрузки**: белый список типов, проверка содержимого картинки, лимиты,
  исполняемые файлы не принимаются, SVG запрещён.
- **Данные**: лежат вне `public_html`; `.htaccess` закрывает `api/data` и
  `smena-data`; копии тоже вне публичной папки.
- **Лимиты**: регистрация, вход, восстановление, обращения — по IP; повторная
  отправка кода не чаще 45 секунд; письмо дважды за 5 минут не уйдёт.
- **CSRF**: API не использует cookie, только токен в теле JSON-запроса, поэтому
  классическая CSRF-атака невозможна.

## 4. Языки

«Все языки мира» — это больше семи тысяч языков, и каждый перевод делает
человек: машинная подстановка слов в юридических текстах и цитатах недопустима.
Сделано другое:

- интерфейс (меню, кнопки, подписи полей, футер) переводится на **10 языков**:
  русский, английский, немецкий, французский, испанский, итальянский,
  португальский, турецкий, арабский (с правосторонним письмом), китайский;
- выбор языка — в верхней панели, запоминается в браузере, передаётся ссылкой
  `?lang=en`;
- тексты материалов остаются на языке автора — это принципиально: перевод
  менял бы цитаты;
- новый язык добавляется одним блоком в `assets/js/i18n.js` — без правки
  страниц.

Дальше можно добавить ещё 10–15 языков по вашему списку и подключить
бесплатный машинный перевод только для интерфейса, помечая его как
автоматический.

## 7. Ночная правка: почта, подтверждение кодом, языки

- **IMAP**: разбор ответа `LIST` переписан. Сервер вправе не брать имя папки в
  кавычки (`* LIST (\HasNoChildren) "/" INBOX`) — такие строки раньше терялись,
  и подключённый ящик выглядел как «сервер не вернул папки». Теперь проверка
  идёт по шагам (соединение → вход → список → папки), недостающие папки
  Sent/Drafts/Trash/Spam создаются автоматически, а в админке видно, на каком
  шаге споткнулись. Плюс запасной вариант: порт 993 (SSL), затем 143 (STARTTLS).
- **Пароль редакции удалён из интерфейса полностью.** Чувствительные действия
  подтверждаются кодом на почту (`action-code` → `action-confirm`), пропуск
  живёт 30 минут. Маршруты `queue`, `review`, `remove`, `portfolio-*`,
  `consent-*`, `claim-director`, `grant-admin`, `mail-setup`, `mail-from`
  принимают только подтверждение, старый пароль не работает.
- **Языки**: 56 языков, включая RTL (арабский, иврит, фарси, урду).

## 8. Почта заработала

- IMAP: перебор формы логина (полный адрес / короткий) и портов 993/143,
  рабочий вариант сохраняется. Ящики подключены, папки заведены автоматически.
- SMTP: сервер отправки подбирается из smtp.<домен>, mail.<домен> × порты
  465/587/25. Отдельная кнопка «Проверить отправку» отправляет письмо самому
  себе и запоминает рабочий вариант. Системные письма идут с noreply@ тем же
  подбором; отправка из раздела «Почта» тоже перебирает варианты.
- ИИ: оставлен один сервис — **DeepSeek** (ключ `sk-…`, API совместим с OpenAI,
  работает из России без VPN). Gemini и Groq отвечали 403 с российских адресов,
  поэтому выбор сервисов убран: одно поле для ключа и кнопка проверки.
- Почта: раздел переделан в карточки состояния — чтение писем, отправка, папки.
  Ввод паролей и адресов серверов с экрана убран: всё настроено на сервере.

## 5. Проверка регистрации

Регистрация без подтверждения почты невозможна — проверено автотестом:
`pending_email`, действия закрыты, при неудачной отправке письма аккаунт
откатывается. Аккаунт остаётся в системе после подтверждения и удаляется по
желанию владельца из кабинета (без потери опубликованных материалов: они
остаются без имени автора).

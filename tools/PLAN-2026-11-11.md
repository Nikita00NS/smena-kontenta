# План переделки сайта, утверждён 11.11.2026

Документ фиксирует, что решено с владельцем проекта и в каком порядке это делается.
Работа идёт в отдельной ветке. На сайт изменения попадают только после слияния в `main`.

### Что ещё нужно от владельца

- Почтовый адрес оператора для согласия и политики. По закону (п. 3 ч. 4 ст. 9 закона № 152-ФЗ) в согласии
  должны стоять имя и адрес оператора. Пока адреса нет, в документах стоят город и почта.
- По желанию — номер в реестре операторов Роскомнадзора.

Данные оператора лежат в одном файле: `tools/docs/project.json`. Меняется он — меняются все документы и сайт.

## Этапы

### 1. Срочное

- [x] Материал принимается только от аккаунта с подтверждённой почтой; публикация без проверки — только по праву.
- [x] Согласие проверяет сервер. Сканы лежат в закрытой папке, а не рядом с картинками.
- [x] Материалы привязаны к аккаунту, старые привязываются при входе автора.
- [x] Состояние пресс-карты считает сервер: кабинет, панель и проверка по номеру видят одно и то же.
- [x] Открытие редакции — заявлением, а не кнопкой.
- [x] Роли: себе не выдать, старшего не снять, директора по слову `force` не получить.
- [x] Очередь согласий и кнопки после решения в панели.
- [x] Печать карт убрана из кабинета и документов.
- [x] Основатели на странице «О проекте».

### Сделано сверх плана — на подтверждение владельцу

- После принятого согласия имя в профиле меняется только через поддержку: оно должно совпадать с документом.
- «Преподаватель» видит только медиашколу — без материалов, людей и поддержки.
- Участник может выйти из редакции, руководитель — исключить с причиной; роль, выданная для работы
  в редакции, при выходе снимается.
- Директор может сменить руководителя редакции и закрыть редакцию (панель → «Редакции»).
- При удалении аккаунта материалы автора снимаются с сайта, сканы согласий и записи медиашколы
  стираются — так записано в политике и соглашении.
- Курс попадает в каталог медиашколы только после публикации руководством школы.
- Журнал действий и журнал писем хранятся не дольше года.

## Как проверять

```
mkdir -p /tmp/sk-tests && cp tools/tests/package*.json /tmp/sk-tests/ && (cd /tmp/sk-tests && npm ci)
export NODE_PATH=/tmp/sk-tests/node_modules
bash tools/tests/run-all.sh          # все проверки подряд
node tools/preview/server.js         # сайт с работающим сервером: http://localhost:8080
```

Что входит в проверки и сколько они идут — `tools/tests/README.md`.

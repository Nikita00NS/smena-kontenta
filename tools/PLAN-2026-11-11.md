# План переделки сайта, утверждён 11.11.2026

Документ фиксирует, что решено с владельцем проекта и в каком порядке это делается.
Работа идёт в отдельной ветке. На сайт изменения попадают только после слияния в `main`.

## Решения владельца

| Вопрос | Решение |

| Оператор персональных данных | Ильин Борис Павлович. Его имя стоит в политике, согласии и заявлении на открытие редакции |

| Что закрыто без согласия | Редактор и отправка материалов, портфолио, заявка на карту, редакции, запись в медиашколу |
| Что открыто без согласия | Чтение сайта, кабинет, загрузка согласия, поддержка |
| Кому согласие не нужно | Только верхним ролям: Директор, Сооснователь |

| Дополнительно одобрено | Уведомления о решениях; отдельное согласие на распространение (ст. 10.1); руководитель редакции видит только своих людей; страница проверки карты; закрыть репозиторий (делает владелец в настройках GitHub) |

### Что ещё нужно от владельца

- Почтовый адрес оператора для согласия и политики. По закону (п. 3 ч. 4 ст. 9 закона № 152-ФЗ) в согласии
  должны стоять имя и адрес оператора. Пока адреса нет, в документах стоят город и почта.
- По желанию — номер в реестре операторов Роскомнадзора.

Данные оператора лежат в одном файле: `tools/docs/project.json`. Меняется он — меняются все документы и сайт.

## Этапы

### 1. Срочное

- [x] Материал принимается только от аккаунта с подтверждённой почтой; публикация без проверки — только по праву.
- [x] Согласие проверяет сервер. Сканы лежат в закрытой папке, а не рядом с картинками.
- [x] Материалы привязаны к аккаунту, старые привязываются при входе автора.
- [x] Состояние пресс-карты считает сервер: кабинет, панель и проверка по номеру видят одно и то же.
- [x] Открытие редакции — заявлением, а не кнопкой.
- [x] Роли: себе не выдать, старшего не снять, директора по слову `force` не получить.
- [ ] Очередь согласий и кнопки после решения в панели.
- [ ] Печать карт убрана из кабинета и документов.
- [ ] Основатели на странице «О проекте».

### 2. Кабинет

- [ ] Вкладки: обзор, материалы, документы, пресс-карта, редакция, школа, сообщения, настройки.
- [ ] Обзор со статусами и следующим шагом.
- [ ] «Команда в браузере» убрана: команда — это редакция на сервере.

### 3. Документы

- [ ] Один сборщик PDF, данные из `tools/docs/project.json`.
- [ ] Официальное оформление.
- [ ] Новое согласие на обработку.
- [ ] Согласие на распространение (ст. 10.1).
- [ ] Документ «О присвоении пресс-карты».
- [ ] Заявление на открытие редакции.

### 4. Панель проекта

- [ ] Доступ по правам с сервера, а не по названию роли.
- [ ] Меню со счётчиками.
- [ ] Люди, согласия, материалы, карты, поддержка, сайт, сервер.

### 5. Редакции и отчёты

- [x] Анкета → заявление → подпись → письмо → решение директора (сервер).
- [ ] Анкета и статус заявления в кабинете, очередь в панели.
- [ ] Отчёты: форма руководителя и автоматическая статистика.

### 6. Медиашкола

- [ ] Курсы, уроки, задания, тесты.
- [ ] Проверка заданий, прогресс.
- [ ] Кабинет ученика и раздел преподавателя.

### После всех этапов

- [ ] Список дальнейших предложений владельцу.
- [ ] Просмотр сайта с работающим сервером: `node tools/preview/server.js`.

# Почта проекта: что сделать и как включить отправку писем

Пока почтовый ящик на домене не создан, восстановление доступа работает без писем:
при регистрации выдаётся код восстановления, а если он потерян — автор оставляет
заявку, и директор с администрацией выдают новый код вручную (раздел «Доступ»
в `/admin`). Это не заглушка: так и задумано, чтобы доступ не зависел от почты.

## Шаг 1. Создать ящик (делает владелец аккаунта хостинга)

1. Панель Sprinthost → раздел «Почта» → домен `smenakontenta.ru`.
2. Создать два ящика:
   - `kod@smenakontenta.ru` — только для кодов восстановления, вход людям не нужен;
   - `hello@smenakontenta.ru` — для писем авторам и партнёрам.
3. Пароли сохранить в менеджере паролей. Никому не пересылать.

## Шаг 2. Включить отправку в коде

В `api/index.php` есть одна строка:

```php
if (!defined('SMENA_MAIL_FROM')) define('SMENA_MAIL_FROM', '');
```

Достаточно вписать адрес отправителя:

```php
if (!defined('SMENA_MAIL_FROM')) define('SMENA_MAIL_FROM', 'kod@smenakontenta.ru');
```

После этого:

- заявка «кода нет» сразу отправляет код письмом (`mailSent: true`);
- в админке кнопка «Выдать код» тоже отправляет письмо, а не показывает код на экране;
- в интерфейсе вместо «ответ придёт, когда появится почта» человек увидит
  «проверьте входящие и папку Спам».

Отправка идёт через локальный `sendmail` хостинга — SMTP-пароль в коде не нужен.

## Шаг 3. Чтобы письма не попадали в спам

1. В панели домена проверить записи DNS: `SPF` (включает сервер Sprinthost)
   и `DKIM` — их выдаёт панель хостинга при включении почты.
2. Отправить тестовое письмо на свой ящик Mail.ru и на Gmail, проверить,
   что оно во «Входящих» и что адрес отправителя выглядит как `kod@smenakontenta.ru`.
3. Письма короткие: код, одна строка объяснения, никаких ссылок и картинок —
   так меньше поводов для фильтров.

## Если понадобится внешний сервис

`mail_send()` в `api/index.php` — единственное место, где отправляется почта.
Когда захочется подключить внешний SMTP (например, Mail.ru для бизнеса),
меняется только эта функция: остальной код её не касается.

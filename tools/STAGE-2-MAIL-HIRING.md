# Этап 2–3: почта домена и приём в команду

Сборка: `2026-11-06-14`. Что сделано в коде, что нужно сделать руками и где
лежат данные.

## 1. Почтовый клиент и ящики

Новые файлы:

- `api/lib/mailer.php` — фирменный макет письма (чёрное на белом, логотип,
  оранжевая кнопка `#ff5c1a`), 14 шаблонов, текстовая MIME-версия,
  журнал доставки `mail-log.json`, правки админа в `mail-templates.json`.
- `api/lib/imap.php` — IMAP-клиент без сторонних библиотек и без расширения
  `imap`: SSL/STARTTLS, LOGIN, LIST/SELECT/UID SEARCH/FETCH/STORE/COPY/APPEND,
  декодирование `=?UTF-8?B?…?=`, multipart, вложения.
- `api/lib/mailbox.php` — маршруты почты: список ящиков, сохранение настроек,
  проверка подключения, папки, письма, вложения, метки, перемещение,
  отправка, черновики, шаблоны, журнал.

Ящики (`smena-data/mailboxes.json`, создаётся сам при первом сохранении):

| ключ | адрес | назначение |
|---|---|---|
| `editorial` | editorial@smenakontenta.ru | переписка с авторами и героями |
| `info` | info@smenakontenta.ru | общие вопросы |
| `noreply` | noreply@smenakontenta.ru | системные письма |
| `support` | support@smenakontenta.ru | обращения |

По умолчанию: IMAP `mail.smenakontenta.ru:993` SSL, SMTP
`smtp.smenakontenta.ru:465` SSL, логин — полный адрес. Если в панели
Sprinthost указан другой сервер, его можно поправить в админке.

Правила, заложенные в код:

- пароль ящика хранится только в `smena-data/mailboxes.json` и в браузер не
  отдаётся — интерфейс знает лишь «пароль задан / не задан»;
- пустое поле пароля означает «оставить прежний»;
- отправка требует явного подтверждения (`confirm: true`) и блокируется,
  если то же письмо уходит повторно в течение 5 минут;
- копия отправленного кладётся в `Sent` (проверяется и русское название
  «Отправленные»);
- вложения: pdf, docx, xlsx, txt, csv, jpg, png, webp, zip; до 6 файлов,
  до 8 МБ вместе; исполняемые не принимаются;
- читать и отправлять может роль с полномочием `mail.use`
  (директор, администрации, техадмин, главный редактор);
- настройки ящиков меняет только `mail.manage`.

## 2. Почта при регистрации

- Регистрация **невозможна без работающей почты**: если SMTP не настроен,
  API отвечает 503 и аккаунт не создаёт. Так не появляются «мёртвые» адреса.
- После регистрации аккаунт получает `status: pending_email` и
  `emailVerified: false`. Вход работает, но отправка материалов, заявки,
  карточка автора и обращения закрыты, пока человек не введёт код из письма.
- Если письмо с кодом не ушло, аккаунт удаляется, чтобы адрес не был занят
  зря: человек может зарегистрироваться снова.
- Код — 6 цифр, живёт 30 минут, повторная отправка не чаще раза в 45 секунд.
- После подтверждения уходит приветственное письмо, событие попадает в журнал
  действий.

## 3. Приём в команду

`api/lib/hiring.php`, данные — `smena-data/hiring.json`.

Этапы: заявка → тест знаний (10 вопросов, порог 70 %, правильные ответы
проверяет сервер и в браузер не отдаёт) → чек-лист (согласия, портфолио,
правила, собеседование, наставник) → согласование.

Принять заявку можно только когда тест сдан и все пункты чек-листа закрыты:
`hiring-decide` отвечает 409 и объясняет, чего не хватает. При приёме роль
аккаунта меняется на «Сотрудник», пишется событие в журнал и уходит письмо.
Отказ требует причины не короче 5 символов, причина уходит человеку.

## 4. Доступы

Новые роли: «Главный редактор» (65), «Технический администратор» (78),
«Сотрудник» (20), «Автор» (12). Полномочия `mail.use`, `hiring.view`,
`hiring.decide` проверяются на сервере.

Маршрут `grant-admin` выдаёт доступ по почте **только с паролем редакции**
(одного токена директора мало). В админке это блок «Выдать админку по почте»
на вкладке «Сервер».

## 5. Что нужно сделать руками (без этого почта не заработает)

1. В панели Sprinthost создать четыре ящика: `editorial@`, `info@`,
   `noreply@`, `support@` на домене `smenakontenta.ru`.
2. Открыть `/admin` → «Почта»: для каждого ящика вписать пароль, сохранить и
   нажать «Проверить» (в блоке «Отправка писем» — проверка SMTP).
3. Проверить серверы и порты: если `smtp.smenakontenta.ru` не отвечает,
   поставить `mail.smenakontenta.ru` и порт 465.
4. Выдать доступ Борису (`6804979@mail.ru`) через блок «Выдать админку
   по почте» на вкладке «Сервер» — нужен пароль редакции. Если аккаунта ещё
   нет, он должен сначала зарегистрироваться и подтвердить почту.

## 6. Что проверено автотестами

`tools/tests/api-checks.js`, 56 проверок на настоящем PHP (php-wasm):
регистрация без подтверждения блокирует действия; ящики закрыты гостем и
участником; пароли ящиков не отдаются; неподключённый ящик не читается;
письмо без подтверждения (428) и из ненастроенного ящика (409) не уходит;
шаблоны писем и предпросмотр работают; шаблоны и журнал меняет только
администрация; заявка в команду, тест, чек-лист, приём, отказ без причины,
запись в журнале — всё на месте.

Запуск:

```
cd tools/tests && npm i php-wasm php-parser && node api-checks.js
node tools/tests/php-syntax.js      # из корня: быстрая проверка синтаксиса PHP
```

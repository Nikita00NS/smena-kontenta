# Карта регионов: откуда данные и как её пересобрать

## Что используется

- **Границы регионов:** GeoJSON-набор [`imsha/russia_geojson_regions_2021`](https://github.com/imsha/russia_geojson_regions_2021)
  (файл `ru.json`, 84 субъекта РФ, названия на русском, границы 2015–2021 годов).
- **Проекция:** равновеликая коническая проекция Альберса (стандартные параллели 50° и 70°,
  центральный меридиан 100° в.д.) — она даёт привычную «изогнутую» форму России.
- **Обработка:** упрощение границ алгоритмом Дугласа — Пекера (допуск 0.035°), отбрасывание
  мелких островов, перенос Чукотки через 180-й меридиан.

Результат — файл `assets/js/map-data.js` (~200 КБ, после сжатия на хостинге — в 2–3 раза меньше).

## Как пересобрать

```bash
# 1. положить ru.json рядом (скачать из репозитория-источника)
# 2. запустить из корня проекта
python3 tools/build-map.py путь/к/ru.json
```

Скрипт перезапишет `assets/js/map-data.js`. Ничего больше менять не нужно:
сайт подхватит новые границы, списки регионов и федеральные округа.

## Что важно проверить перед публичным запуском

1. **Состав регионов.** В наборе 84 субъекта: нет Севастополя, а спорные территории
   отмечены так, как решил автор набора. Для публичного сайта состав и подписи нужно
   согласовать с юридической точки зрения.
2. **Актуальность границ.** Набор датирован 2021 годом; если границы или названия
   менялись — нужен более свежий источник.
3. **Условия использования источника.** У репозитория-источника нужно проверить лицензию
   и указать её на сайте (`О проекте` → раздел об источниках), либо заменить набор на
   официальные данные (например, Росстат / OpenStreetMap) с проверенной лицензией.
4. **Крым и другие чувствительные территории** — отдельное решение проекта, а не техническое.

## Альтернативы, если понадобится другой стиль карты

- `navizv/Russian_topology_map` — схематичная (не географическая) карта регионов в виде
  диаграммы смежности. Выглядит дизайнерски, но не показывает реальную географию.
- `timurkanaz/Russia_geojson_OSM` — детальные границы из OpenStreetMap (файлы очень большие,
  потребуется более сильное упрощение).
- Настоящая интерактивная карта с зумом и подписями — Leaflet + OpenStreetMap; но это
  внешняя библиотека и тайлы, которые нужно проверять по условиям использования.

# Смена контента — сайт проекта

Молодёжное медиа, медиашкола и сообщество авторов из регионов.
Главная особенность сайта — интерактивная карта России: выбираешь регион и видишь материалы оттуда.

Это **статический сайт**: обычные HTML-файлы, которые открываются в браузере и бесплатно
публикуются на GitHub Pages или Cloudflare Pages. Никаких серверов, баз данных и подписок —
это важно при бюджете около нуля.

---

## 1. Как посмотреть сайт

**Способ 1 (самый простой).** Открыть файл `index.html` двойным щелчком.
Сайт работает прямо с диска, интернет не нужен.

**Способ 2 (как на настоящем сервере).** В папке проекта выполнить:

```bash
python3 -m http.server 8000
```

и открыть в браузере `http://localhost:8000`.

---

## 2. Как менять содержание (без программирования)

Почти весь текст сайта лежит в одном файле — **`assets/js/data.js`**. Внутри есть
подробные комментарии, но коротко:

| Что нужно | Где менять |
|---|---|
| Почта, Telegram, название | блок `brand` в начале `data.js` |
| Авторы и их подписи | массив `authors` |
| Материалы (заголовки, тексты, даты) | массив `articles` |
| Рубрики и форматы | массивы `topics` и `formats` |

Чтобы добавить материал, скопируйте любой блок `{ ... }` в `articles` и поменяйте значения.
Поле `region` — это латинский адрес региона (его видно в адресной строке на странице региона,
например `moskva`, `respublika-tatarstan`).

Фотографии кладите в `assets/img/`, маленькие версии для карточек — в `assets/img/thumb/`.
В поле `image` пишите путь от корня сайта: `assets/img/moy-snimok.jpg`.

Страницы `about.html`, `media-school.html`, `join.html`, `partners.html` — обычные HTML:
текст можно править прямо в них.

## 3. Как опубликовать сайт бесплатно

### Вариант А. GitHub Pages (рекомендую начать с него)

1. Создать на GitHub репозиторий, например `smena-kontenta`.
2. Загрузить туда все файлы проекта (можно просто «перетащить» их в веб-интерфейсе GitHub).
3. В репозитории: **Settings → Pages → Source: Deploy from a branch → Branch: main, папка / (root) → Save**.
4. Через минуту сайт будет доступен по адресу `https://ваш-логин.github.io/smena-kontenta/`.

Файл `.nojekyll` в проекте уже лежит — он нужен, чтобы GitHub не ломал папки и шрифты.

### Вариант Б. Cloudflare Pages

1. Зарегистрироваться на Cloudflare, раздел **Workers & Pages → Create → Pages → Upload assets**.
2. Перетащить папку проекта. Настройки сборки оставить пустыми (это статика).
3. Получите адрес вида `smena-kontenta.pages.dev`.

Оба варианта бесплатны и дают рабочий HTTPS. Свой домен можно подключить позже —
тогда платить придётся только за его продление, обычно 1–2 тысячи рублей в год.

### Важно перед публикацией

- Заменить демонстрационные тексты и фотографии на настоящие.
- Вписать рабочий контакт в `brand.email` и `SC.brand.telegram` в `data.js`.
- Убрать плашку «Прототип · демо-материалы» в `assets/js/app.js` (функция `mountHeader`, класс `badge-demo`).
- Проверить состав регионов на карте и права на изображения.

## 4. Что здесь уже есть

- **Главная**: лента редакции, главный материал, бегущая строка новостей.
- **Карта регионов**: 84 субъекта РФ, поиск региона по названию, фильтр по федеральным округам,
  масштаб и перетаскивание, переключение на список регионов, доступ с клавиатуры.
- **Страница региона**: материалы местных авторов, мини-карта, честное сообщение,
  если публикаций пока нет.
- **Лента материалов**: фильтры по теме, формату, округу, региону, поиск, сортировка.
- **Страница материала**: обложка, автор, текст, теги, «поделиться», похожие материалы.
- **Медиашкола**, **О проекте**, **Присоединиться** (форма-письмо), **Партнёрам**, страница 404.
- **Поиск по всему сайту** (иконка в шапке или клавиша `/`).
- Адаптивность под телефон, планшет и компьютер; поддержка клавиатуры и `prefers-reduced-motion`.

## 5. Структура файлов

```
index.html            главная
news.html             все материалы с фильтрами
article.html          страница материала  (?id=...)
region.html           страница региона    (?r=...)
media-school.html     медиашкола
about.html            о проекте, команда, план развития
join.html             присоединиться, форма заявки
partners.html         партнёрам
404.html              страница ошибки
assets/css/site.css   все стили (цвета — в начале файла, блок 02)
assets/js/data.js     ВЕСЬ КОНТЕНТ
assets/js/app.js      логика: шапка, поиск, карта, лента, страницы
assets/js/map-data.js границы регионов (сгенерированный файл, не править руками)
assets/fonts/         шрифты Unbounded, Golos Text, JetBrains Mono (лицензия OFL)
assets/img/           изображения
tools/build-map.py    скрипт сборки карты
tools/README.md       откуда взята карта и как её пересобрать
```

## 6. Лицензии и источники

- Шрифты: Unbounded, Golos Text, JetBrains Mono — SIL Open Font License 1.1.
- Границы регионов: проект `imsha/russia_geojson_regions_2021` (GeoJSON регионов РФ);
  подробности и порядок проверки — в `tools/README.md`.
- Изображения: сгенерированы специально для прототипа, чтобы не нарушать чужие права.
  Их нужно заменить на фотографии авторов проекта.
- Тексты материалов — демонстрационные, написаны как примеры оформления.

## 7. Что дальше (по шагам)

1. Показать сайт потенциальным участникам и собрать замечания по дизайну и структуре.
2. Определить регион первого запуска и возраст участников.
3. Найти редактора и 3–5 авторов.
4. Заменить демо-материалы на первые настоящие (проверить факты и права на фото).
5. Подключить нормальную почту и, при желании, форму без сервера (например, Formspree/Telegram-бот).
6. Опубликовать сайт на GitHub Pages и дать ссылку людям.
7. Собрать заявку на грант: проблема, аудитория, цель, план, бюджет, результаты.

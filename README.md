# Смена контента — сайт проекта

Молодёжное медиа, медиашкола и сообщество авторов из регионов.
Главная особенность — интерактивная карта России: выбираешь регион и видишь материалы оттуда.

Сайт **статический**: обычные HTML-файлы, без серверов и подписок. Открывается двойным щелчком
по `index.html` и работает на обычном хостинге. Живой адрес — https://smenakontenta.ru

---

## 1. Что уже работает

**Медиа**
- Главная в формате редакционной страницы: главный материал, лента, бегущая строка, рубрики,
  форматы, «лица проекта», возможности, три шага до первой публикации.
- Лента материалов с фильтрами: тема, формат, федеральный округ, регион, поиск, сортировка.
- Страница материала: обложка, автор, лид, буквица, цитаты, подзаголовки, теги, полоса
  прогресса чтения, похожие материалы.
- Поиск по всему сайту (иконка в шапке или клавиша `/`).

**Карта регионов**
- 84 субъекта РФ: поиск, фильтр по федеральным округам, масштаб, перетаскивание,
  переключение на список, работа с клавиатуры.
- Легенда «есть материалы / публикаций пока нет», подсказки при наведении.
- Страница региона: материалы оттуда, мини-карта, честное сообщение, если публикаций нет.

**Аккаунты, согласие и материалы**
- Регистрация с 14 лет, вход по почте и паролю, подтверждение почты кодом из письма.
- Материал отправляется только из подтверждённого аккаунта с **принятым согласием** на обработку
  данных. Согласие — два подписанных от руки листа (на обработку и на распространение), сканы
  загружаются в кабинете и хранятся на сервере в закрытой папке; принимает их редакция.
- Без согласия открыты: чтение сайта, кабинет, загрузка согласия, поддержка. Закрыты: редактор и
  отправка материалов, портфолио, заявка на пресс-карту, редакции, запись в медиашколу.
- Материал: черновик → на проверке → опубликован или возвращён с замечанием. Статус решает сервер.

**Личный кабинет** (`/profile`) — вкладки: обзор со следующим шагом, материалы, документы,
пресс-карта, редакция, медиашкола, сообщения, профиль.

**Пресс-карта**
- Заявка из кабинета после 5 публикаций; сотруднику редакции карту выдают по должности.
- Карта — запись на сервере с номером `СК-2026-0001`: действует год, продлевается, может быть
  приостановлена или отозвана. Пластик не печатается и не рассылается.
- Документ «Решение о присвоении пресс-карты» с подписями директора и сооснователя — `/card-doc`.
- Проверка подлинности по номеру — `/verify`, открыта всем.

**Региональные редакции**
- Редакцию открывает директор по заявлению руководителя: анкета в кабинете → заявление `/editorial-doc`
  → подписанный скан на почту → решение в панели.
- Руководитель принимает авторов, первым проверяет материалы своих людей, раз в месяц сдаёт отчёт:
  текст пишет сам, цифры считает сервер.
- Участник может выйти, руководитель — исключить с причиной; сменить руководителя или закрыть
  редакцию может директор.

**Медиашкола** (`/media-school`)
- Курсы из уроков: текст, видео ссылкой на VK Видео или Rutube, тест или задание.
- Уроки открываются по порядку, тест проверяет сайт, задание — преподаватель; прогресс и баллы
  хранит сервер.
- Преподаватель собирает курсы и проверяет работы в панели; в каталог курс попадает после
  публикации руководством школы.

**Панель проекта** (`/admin`)
- Доступ и набор разделов определяет сервер по роли: обзор со счётчиками, материалы, согласия,
  пресс-карты, редакции и отчёты, медиашкола, люди, команда, поддержка и почта, сайт, сервер.
- Руководитель редакции видит только своих людей и их материалы; преподаватель — только школу.
- Значимые действия (решение по согласию, карте, редакции, смена роли) подтверждаются кодом из письма.

**Документы** (`/docs`) — восемь PDF в `assets/docs/`: два бланка согласия, политика обработки
персональных данных, пользовательское соглашение, кодекс редакции, памятка автору, программа
медиашколы, пресс-кит. Собираются одной командой из одного набора данных (см. раздел 3).

**Оформление**
- Чёрная тема: почти чёрный фон, светлый текст, оранжевый акцент. Все цвета — в блоке токенов
  в начале `site.css` (раздел 02) и переопределены один раз в разделе 18.
- Логотип: `assets/img/logo.png` (белый), `logo-dark.png` (для PDF), `logo-mark.png`,
  фавиконки 32/128/180 px.
- Анимации: появление блоков при прокрутке, счётчики цифр, параллакс главного фото,
  бегущая строка. Отключаются при `prefers-reduced-motion`.

## 2. Как посмотреть сайт

Сайту нужен сервер: вход, согласия, очереди и панель работают через `api/index.php`.
Посмотреть всё это без хостинга можно так (нужен Node.js 20+):

```bash
mkdir -p /tmp/sk-tests && cp tools/tests/package*.json /tmp/sk-tests/ && (cd /tmp/sk-tests && npm ci)
NODE_PATH=/tmp/sk-tests/node_modules node tools/preview/server.js
```

и открыть `http://localhost:8080`. Это копия сайта с настоящим кодом сервера и демонстрационными
людьми; данные живут в памяти. Список демо-аккаунтов и письма, которые «отправил» сайт (в том числе
коды подтверждения), — на странице `http://localhost:8080/__preview`.

Проверки проекта запускаются одной командой: `bash tools/tests/run-all.sh` (подробности —
`tools/tests/README.md`).

## 3. Как менять содержание

Почти весь текст — в файле **`assets/js/data.js`** (внутри комментарии):

| Что менять | Где |
|---|---|
| Почта, название, город, год | блок `brand` (почта также в панели проекта) |
| Документы на странице «Документы» | массив `docs` |
| Авторы и подписи | массив `authors` |
| Материалы редакции | массив `articles` |
| Рубрики и форматы | `topics`, `formats` |

Фотографии — в `assets/img/`, миниатюры для карточек — в `assets/img/thumb/`.
Страницы `about.html`, `media-school.html`, `partners.html` — обычный HTML, текст правится в них.

### Документы (PDF)

```bash
pip install reportlab pypdf
python3 tools/docs/build.py          # собрать все PDF и обновить список на странице /docs
python3 tools/docs/sync-project.py   # перенести данные проекта на сайт
```

Имена директора и оператора, почта, сроки — в одном файле **`tools/docs/project.json`**.
Тексты — в `tools/docs/legal.py` (политика, соглашение, согласия) и `tools/docs/guides.py`
(пресс-кит, кодекс, памятка, программа). Подробно — `tools/docs/README.md`.

### Логотип

```bash
python3 tools/make-logo.py путь/к/новому-логотипу.png
```

Скрипт сделает белый логотип для сайта, чёрный для документов, знак и все фавиконки.

## 4. Где хранятся данные (важно понимать)

Аккаунты, материалы, согласия, карты, редакции, отчёты и курсы хранит **сервер**: PHP-скрипт
`api/index.php` и файлы в папке `smena-data/` на хостинге — вне `public_html`, из браузера она не
открывается и в репозиторий не попадает.

- В браузере остаются только черновики материалов, тема оформления и копия статусов для быстрого
  показа; решения всегда принимает сервер.
- Права проверяются на сервере по таблице ролей `api/lib/permissions.php`. Интерфейс может что-то
  скрывать, но открыть закрытое через него нельзя.
- Сканы согласий с паспортными данными лежат в `smena-data/consents/`; их видит сам человек и
  сотрудники с правом проверки, каждое открытие пишется в журнал.
- При удалении аккаунта стираются имя, почта, сканы согласий, записи медиашколы; материалы
  снимаются с сайта.

Весь клиентский обмен с сервером идёт через `assets/js/store.js`.

## 5. Как опубликован сайт

**Адрес:** https://smenakontenta.ru
**Хостинг:** Sprinthost, виртуальный. Серверы в России — сайт открывается без VPN.
**Папка сайта на хостинге:** `~/domains/smenakontenta.ru/public_html/`

### Выкладка автоматическая

Файл `.github/workflows/deploy.yml` при каждом коммите в ветку `main` отправляет
сайт на хостинг по FTP. Готовый текст лежит в репозитории как `tools/deploy-sprinthost.yml`:
его нужно один раз скопировать в `.github/workflows/deploy.yml` через кнопку
**Add file → Create new file** на GitHub (у автоматики нет прав создавать файлы выкладки). Логин и пароль лежат в GitHub Secrets
(`FTP_SERVER`, `FTP_USERNAME`, `FTP_PASSWORD`) — в коде и в переписке их нет.

Порядок работы: изменил файл → коммит в `main` → через 1–2 минуты сайт обновлён.
Ход выкладки виден во вкладке **Actions** репозитория.

### Что настроено в корне сайта

- `.htaccess` — `index.html` открывается как главная (а не стандартная заглушка
  хостинга), красивая страница 404, сжатие, кэш картинок и шрифтов, правильные
  типы файлов, запрет показа списка файлов в папках;
- `robots.txt` — служебные страницы (`admin`, `profile`, `write`) закрыты от поиска,
  указана карта сайта;
- `sitemap.xml` — карта сайта для Яндекса и Google;
- в каждой странице — `canonical`, Open Graph и картинка превью
  `assets/img/og-cover.jpg` (1200 × 630) для ссылок в соцсетях и мессенджерах.

### Если понадобится другой хостинг

Достаточно поменять `server-dir` в `deploy.yml` и три секрета. Код от хостинга
не зависит: это обычные HTML, CSS и JavaScript.

## 7. Документы и закон

Сайт обрабатывает персональные данные, в том числе несовершеннолетних, поэтому по закону № 152-ФЗ:

- оператор персональных данных — один человек, он назван в `tools/docs/project.json` и стоит в
  политике, обоих согласиях и заявлении на открытие редакции; документы утверждает генеральный директор;
- согласие на обработку — письменное, один лист: ФИО, паспорт, адрес, перечень данных, срок, отзыв,
  подпись; автору младше 18 лет нужна ещё подпись родителя;
- согласие на распространение (ст. 10.1) — отдельный лист: без него имя автора не публикуется;
- политика и пользовательское соглашение — PDF, ссылки в подвале и на странице «Документы»;
  галочка согласия с ними обязательна при регистрации.

Что нужно от владельца, прежде чем считать документы готовыми:

1. **Почтовый адрес оператора** — вписать в `tools/docs/project.json` (`operator.address`) и
   пересобрать документы. Без адреса согласие не соответствует п. 3 ч. 4 ст. 9 закона; сборщик
   напоминает об этом при каждом запуске.
2. **Юрист.** Тексты подготовлены по закону, но это не юридическое заключение: их нужно показать
   юристу — особенно всё, что касается несовершеннолетних авторов и оператора.
3. **Уведомление в Роскомнадзор** — черновики в `tools/rkn-*.md`.

## 8. Лицензии и источники

- Логотип — собственная айдентика проекта (`assets/img/logo*.png`).
- Шрифты: Unbounded, Golos Text, JetBrains Mono — SIL Open Font License 1.1.
- Границы регионов: набор `imsha/russia_geojson_regions_2021` (см. `tools/README.md`).
- Изображения сгенерированы для прототипа: чужих прав не нарушают, но перед публичным
  запуском их нужно заменить на снимки авторов.
- Образцовых материалов в ленте больше нет: на сайте только то, что опубликовали авторы.

## 9. Что дальше

Полный список — в `RELEASE.md`. Коротко: указать ФИО и ИНН учредителей, завести рабочую почту,
наполнить ленту реальными материалами, подключить сервер, чтобы авторы и редакторы
работали с разных устройств.

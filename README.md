# Смена контента — сайт проекта

Молодёжное медиа, медиашкола и сообщество авторов из регионов.
Главная особенность — интерактивная карта России: выбираешь регион и видишь материалы оттуда.

Сайт **статический**: обычные HTML-файлы, без серверов и подписок. Открывается двойным щелчком
по `index.html` и бесплатно публикуется на GitHub Pages или Cloudflare Pages.

---

## 1. Что уже работает

**Медиа**
- Главная в формате редакционной страницы: главный материал, живая лента, бегущая строка,
  рубрики, форматы, «лица проекта», возможности.
- Лента материалов с фильтрами: тема, формат, федеральный округ, регион, поиск, сортировка.
- Страница материала: обложка, автор, лид, буквица, цитаты, подзаголовки, теги, «поделиться»,
  полоса прогресса чтения, похожие материалы.
- Поиск по всему сайту (иконка в шапке или клавиша `/`).

**Карта регионов**
- 84 субъекта РФ, поиск региона по названию, фильтр по федеральным округам, масштаб,
  перетаскивание, переключение на список, работа с клавиатуры.
- Легенда «есть материалы / публикаций пока нет», подсказки при наведении.
- Страница региона: материалы оттуда, мини-карта, честное сообщение, если публикаций нет.

**Аккаунты и публикация (без заявок)**
- Регистрация и вход: имя, почта, пароль, регион, роль (`join.html`).
- Личный кабинет (`profile.html`): пресс-карта автора с номером, статистика, публикации и
  черновики, настройки профиля, печать пресс-карты.
- Редактор материала (`write.html`): заголовок, лид, текст, тема, формат, регион, обложка
  (файл или ссылка), сохранение черновика и публикация.
- Опубликованный материал сразу попадает в ленту, на главную и на страницу своего региона,
  с подписью автора и пометкой «автор проекта».

**Документы** (`docs.html`)
- Пресс-кит, положение о редакции, памятка автору, программа медиашколы, согласие на публикацию —
  пять готовых PDF в `assets/docs/`. Пересобираются скриптом `tools/build-docs.py`.

**Оформление**
- Анимации: появление блоков при прокрутке с каскадом, счётчики цифр, параллакс главного фото,
  бегущая строка, плавные наведения, прогресс чтения. Всё отключается при
  `prefers-reduced-motion`.
- Адаптив под телефон, планшет и компьютер, поддержка клавиатуры и экранных дикторов.

## 2. Как посмотреть сайт

**Способ 1.** Открыть `index.html` двойным щелчком — работает прямо с диска.

**Способ 2.** Как на настоящем сервере:

```bash
python3 -m http.server 8000
```

и открыть `http://localhost:8000`.

## 3. Как менять содержание

Почти весь текст — в файле **`assets/js/data.js`** (внутри подробные комментарии):

| Что менять | Где |
|---|---|
| Почта, Telegram, название | блок `brand` |
| Авторы и подписи | массив `authors` |
| Материалы редакции | массив `articles` |
| Рубрики и форматы | `topics`, `formats` |
| Документы | `docs.html` + PDF в `assets/docs/` |

Фотографии — в `assets/img/`, миниатюры для карточек — в `assets/img/thumb/`.

Страницы `about.html`, `media-school.html`, `partners.html`, `docs.html` — обычный HTML,
текст правится прямо в них.

### Документы (PDF)

```bash
pip install reportlab
python3 tools/build-docs.py
```

Скрипт пересобирает все пять PDF из текста внутри `tools/build-docs.py`.
Меняете формулировки в скрипте — пересобираете — файлы на сайте обновляются.

## 4. Как работает регистрация (важно понимать)

Сейчас аккаунты, черновики и публикации хранятся **в браузере** (`localStorage`).
Это значит:

- регистрация, публикация и пресс-карта работают по-настоящему;
- но материалы видны только на том устройстве, где их создали;
- пароль хранится в виде хеша, однако это **не** серверная система входа.

Что делать, когда понадобится, чтобы авторы видели работы друг друга:

1. Зарегистрировать бесплатный проект в Supabase (или Firebase) — это база данных с входом.
2. В `assets/js/store.js` заменить чтение/запись `localStorage` на запросы к Supabase.
   Весь остальной сайт менять не нужно: он общается с данными только через этот файл.
3. Пароли, подтверждение почты и права доступа берёт на себя сервис.

Файл `store.js` специально написан отдельно: это единственное место, которое придётся
переписать при переходе на настоящий сервер.

## 5. Как опубликовать сайт бесплатно

### GitHub Pages

1. Создать репозиторий на GitHub.
2. Загрузить все файлы проекта.
3. **Settings → Pages → Source: Deploy from a branch → Branch: main, папка / (root) → Save.**
4. Через минуту сайт доступен по адресу `https://ваш-логин.github.io/имя-репозитория/`.

Файл `.nojekyll` уже лежит в проекте — он нужен, чтобы GitHub не ломал папки и шрифты.

### Cloudflare Pages

**Workers & Pages → Create → Pages → Upload assets**, перетащить папку проекта.
Настройки сборки оставить пустыми.

### Перед публикацией

- вписать рабочую почту и Telegram в `brand` внутри `data.js`;
- заменить материалы редакции на настоящие (сейчас в ленте — примеры оформления);
- проверить права на фотографии;
- проверить состав регионов на карте (`tools/README.md`);
- решить, нужен ли сразу сервер для аккаунтов (см. раздел 4).

## 6. Структура файлов

```
index.html            главная
news.html             все материалы с фильтрами
article.html          страница материала  (?id=...)
region.html           страница региона    (?r=...)
media-school.html     медиашкола
docs.html             документы и пресс-кит
about.html            о проекте, команда, план развития
partners.html         партнёрам
join.html             регистрация и вход
profile.html          личный кабинет и пресс-карта
write.html            редактор материала
404.html              страница ошибки

assets/css/site.css   все стили (цвета — блок 02, компоненты — блоки 17+)
assets/js/data.js     КОНТЕНТ: материалы, авторы, рубрики, контакты
assets/js/store.js    аккаунты, черновики, публикации (localStorage)
assets/js/app.js      логика: шапка, поиск, карта, лента, кабинет, редактор
assets/js/map-data.js границы регионов (генерируется, не править руками)
assets/fonts/         Unbounded, Golos Text, JetBrains Mono (OFL)
assets/img/           изображения
assets/docs/          PDF-документы
tools/build-map.py    сборка карты из GeoJSON
tools/build-docs.py   сборка PDF-документов
tools/README.md       откуда взята карта и как её проверить
```

## 7. Лицензии и источники

- Шрифты: Unbounded, Golos Text, JetBrains Mono — SIL Open Font License 1.1.
- Границы регионов: набор `imsha/russia_geojson_regions_2021` (см. `tools/README.md`).
- Изображения сгенерированы для прототипа: чужих прав не нарушают, но перед публичным
  запуском их нужно заменить на снимки авторов.
- Тексты в ленте — примеры оформления, а не описание реальных событий.
- PDF-документы — рабочие черновики (версия 0.1); форму согласия на публикацию стоит
  показать юристу.

## 8. Что дальше

1. Показать сайт людям, собрать замечания по дизайну и структуре.
2. Определить регион первого запуска и возраст участников.
3. Найти редактора и 3–5 авторов, выдать им аккаунты.
4. Заменить примеры материалов на первые настоящие, проверить факты и права на фото.
5. Подключить сервер для аккаунтов (Supabase) и нормальную почту.
6. Опубликовать сайт на GitHub Pages и дать ссылку.
7. Собрать грантовую заявку по пресс-киту и положению о редакции.
